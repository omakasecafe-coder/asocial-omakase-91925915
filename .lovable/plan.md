# Completar la activación del correo

El dominio `notify.asocialcafe.com` ya está verificado correctamente. El estado **Setting up** corresponde a la última etapa interna: Lovable está confirmando que la entrega de correos esté lista. No hay un problema de DNS ni un cambio pendiente en la aplicación.

## Siguiente paso

1. Esperar a que la preparación cambie automáticamente a **Active**; no eliminar ni modificar los registros NS actuales.
2. Volver a comprobar el estado después de un breve periodo. Si permanece en **Setting up** durante varias horas, revisar **Cloud → Emails** y usar **Rerun Setup** o **Verify Domain** si aparece esa opción.
3. Cuando figure **Active**, enviar ambos mensajes desde **Probar correo**: resumen de reserva y confirmación de pago.
4. Revisar los eventos de entrega para confirmar que fueron aceptados o identificar cualquier rechazo, rebote o supresión.

## Criterio de éxito

- El dominio aparece como **Active**.
- Los dos envíos de prueba aparecen como enviados y llegan a la dirección indicada.
